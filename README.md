=> Student Performance Dashboard

A Python-based application for managing student records, analyzing academic performance, and visualizing results through graphs and charts.

📌 Project Overview

The Student Performance Dashboard helps users organize student information, record subject marks, calculate performance, and understand academic results through data visualization.

This project demonstrates the practical use of Python programming, file handling, data analysis, and graphical user interfaces.

🎯 Objectives

- Manage student records efficiently.
- Store and retrieve student data.
- Analyze marks and academic performance.
- Visualize results using graphs and charts.
- Apply Python programming and object-oriented concepts.

✨ Features

- Student record management
- Subject-wise marks and performance analysis
- CSV-based data storage
- Graphical user interface
- Data visualization using Matplotlib
- Numerical operations using NumPy

🛠️ Technologies Used

- **Language:** Python
- **GUI:** Tkinter
- **Data Storage:** CSV
- **Data Analysis:** NumPy
- **Visualization:** Matplotlib
- **Version Control:** Git and GitHub

⚙️ Installation and Setup

1. Clone the repository

```bash
git clone https://github.com/Mantu-code/student-performance-dashboard.git
```

2. Open the project folder

```bash
cd student-performance-dashboard
```

3. Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

4. Install dependencies

```bash
pip install numpy matplotlib
```

If a `requirements.txt` file is available, you can install the listed dependencies using:

```bash
pip install -r requirements.txt
```

5. Run the application

```bash
python3 student_performance.py
```

Use the actual entry-point filename if it differs. If the project includes a separate web interface, follow its corresponding startup instructions as well.
